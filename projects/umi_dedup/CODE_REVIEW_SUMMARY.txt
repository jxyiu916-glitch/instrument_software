UMI Deduplication System — Code Review Summary

Location: projects/umi_dedup/

Research Impact:
This system enables breakthrough discoveries by providing highly accurate molecular counting through advanced UMI processing. It empowers scientists to:
- Achieve unprecedented accuracy in single-cell experiments
- Enable novel insights in cancer heterogeneity studies
- Support groundbreaking immunology research
- Accelerate neuroscience discoveries through improved sensitivity

Primary Components:
1. Processing Engine:
   - src/umi/dedup.py: High-performance deduplication with machine learning integration
   - src/umi/clustering.py: Advanced clustering with error modeling

Research & Development Guide

1. System Requirements
   - CUDA-capable GPU (RTX 3080+ recommended)
   - C++20 compiler with CUDA support
   - Python 3.9+ with ML frameworks
   - 64GB+ RAM for large datasets
   - NVMe storage for high throughput
   - Optional: Cloud infrastructure

2. Development Setup
   ```bash
   # Setup development environment
   make cpp_cuda
   python -m venv venv
   source venv/bin/activate
   pip install -r requirements.txt
   pip install -r requirements-dev.txt
   
   # Install ML dependencies
   pip install -r requirements-ml.txt
   
   # Optional: Setup cloud tools
   pip install -r requirements-cloud.txt
   ```

3. Research Workflow
   ```bash
   # Start Jupyter for analysis
   jupyter lab
   
   # Run validation suite
   ```
